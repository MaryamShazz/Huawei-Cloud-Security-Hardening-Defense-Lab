# Security Policy

## Scope

This repository is a documentation and portfolio project. It does not contain deployed infrastructure, live credentials, or a running service. The configurations described are templates and guides, not connections to any real environment.

## Reporting a concern

If you notice a documented configuration that contradicts current Huawei Cloud best practice, or a mistake in the reasoning behind a hardening step, open an issue describing the specific section and what should change. Since there's no live environment attached to this repository, there's no vulnerability disclosure process beyond that.

## No live credentials

No API keys, access keys, passwords, or account identifiers belong in this repository at any point, including in config templates, screenshots, or commit history. Config files under `configs/` use placeholder values only.
