Every result below comes from real code in backend/app.py evaluating a simplified rule model of this repository's architecture — it is not live Huawei Cloud data. There is no "HUAWEI CLOUD — LIVE" mode in this build; see dashboard/backend/README.md for what a real live-mode integration would require. Changing an input (like a source IP) and re-running a test can change the outcome, since the check is a genuine rule evaluation, not a fixed response.
