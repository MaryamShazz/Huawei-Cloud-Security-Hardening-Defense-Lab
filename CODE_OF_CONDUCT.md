# Code of Conduct

## Expectation

Keep discussion in issues and pull requests focused and respectful. Disagreements about a technical approach are fine and expected; personal attacks aren't.

## Scope

This applies to any interaction in this repository's issues, pull requests, and discussions.

## Reporting

If something in this repository's discussion space becomes disrespectful or off-topic in a disruptive way, flag it by opening an issue tagged accordingly, or contact the repository owner directly.
