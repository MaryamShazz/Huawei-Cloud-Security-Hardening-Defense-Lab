# Contributing

This started as a solo portfolio project, but corrections and suggestions are welcome.

## Suggesting a change

Open an issue describing what you'd change and why, referencing the specific file (a module in `docs/`, an item in `checklists/`, or a config template under `configs/`). Pull requests are welcome for small, well-scoped fixes; larger changes are easier to discuss in an issue first.

## Style

Documentation in this repository follows the format described in `docs/theme-style-guide.md`. New modules should keep the same structure (objective, why it matters, configuration, screenshots, security benefit, best practices, security engineer's notes) so the repository stays consistent.

## Config templates

Anything added under `configs/` should use placeholder values, never real account identifiers, keys, or IP ranges tied to an actual deployment.
