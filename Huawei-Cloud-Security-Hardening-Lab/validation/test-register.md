# Security Test Register

*Status note:* No live Huawei Cloud environment has been deployed yet. Every test below is documented as a designed test procedure, what would be run, against what, and what result would confirm the control works, not as a result actually observed in a live account. Where this register previously said "PASS," that was inaccurate and has been corrected here. A locally runnable simulation of these tests exists in [`local-lab/`](../local-lab/README.md) and is clearly labeled as a simulation, not live Huawei Cloud telemetry, see the note at the bottom of this file for how its results relate to this register.

Full narrative detail for each test is in [`validation-results.md`](validation-results.md); the scenario-level walkthroughs are in [`../simulations/`](../simulations/).

## What "Designed" means here

Each test has a specific source, target, action, and expected outcome written down in enough detail to actually execute it once a Huawei Cloud account is provisioned. "Designed" is not a placeholder for "unknown", it means the test procedure itself has been fully specified and reviewed, and the only missing piece is a live environment to run it against.

## What "Live Execution: Pending deployment" means

None of these tests have been run against a real Huawei Cloud account. This register will be updated to PASS, FAIL, or PARTIAL, per test, only once each one is actually executed and the real result observed, at which point the corresponding evidence record in [`../evidence/`](../evidence/) should also be filled in with the real screenshot or log.

## Local simulation results (separate from this register)

[`local-lab/`](../local-lab/README.md) is a runnable local application that models this environment's rules (IP allow-lists, subnet routing, threshold logic) and lets you actually execute something resembling T-001 through T-009 against that local model, with real output generated by real code running on your machine. Its results are genuine in the sense that the simulator actually runs and actually evaluates the rule, but they are evaluations of a local model, not observations of live Huawei Cloud infrastructure. The local lab UI labels every result "LOCAL SIMULATION" for exactly this reason, and its results are not copied into this table.
